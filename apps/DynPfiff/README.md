# DynPfiff 1.1

Dynamic-DNS style IP updater that lives in the system tray. It detects the local IP
addresses, calls a configurable update URL every N minutes and writes an HTML file from
a template so a home server could be reached by name over a dial-up connection.
Released under the GPL on <http://www.ractive.ch/gpl/dynpfiff.html> (1999-2001).
Third-party classes: Joerg Dentler's CRegBinding, Paul DiLascia's tray icon code.
