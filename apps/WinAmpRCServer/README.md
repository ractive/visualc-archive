# WinAmpRC 1.0 (WinAmpRCServer)

Small dialog application that listens on a configurable TCP port and drives Winamp
through its IPC API (`FRONTEND.H` from the Winamp SDK) from remote text commands such
as play, pause, next and volume. It is the PC side of a phone remote control
(2002-2003). `WinAmpControl` carries a GPL-2.0 header; the rest states no licence.
