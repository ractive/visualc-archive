# MyIPWinClient 3.41

Windows client for the www.myip.org dynamic DNS service (13 Aug 2001). Runs in the
system tray, detects the machine's current IP addresses, lets you create an account,
manage hosts and passwords and pushes IP updates to the service. The service no longer
exists. GPL-2.0 (`gpl.txt`). Third-party classes: Chris Maunder's CHyperLink, Joerg
Dentler's CRegBinding, Paul DiLascia's tray icon code.
