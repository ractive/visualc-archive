# NTMessenger 1.0

Sends Windows NT messenger service popups (what `net send` does) to one or many
computers of a domain. It enumerates the domain and primary domain controller, keeps
an optional extra `hosts` list for machines that do not show up in the network
neighbourhood and has a multiple-recipients dialog and a tray icon. 2000-2001, GPL
according to the About box. The author's private `hosts` file was removed on import.
Third-party classes: Joerg Dentler's CRegBinding.
