# NetConfigurator 1.0

Saves and applies named IP configurations (address, subnet mask, gateway, DNS servers,
DHCP on or off) so a laptop can switch between networks with one click. The settings are
applied with `netsh` and stored in a settings file next to the program.
Released under the GPL on <http://www.ractive.ch/gpl/netconfigurator.html> (2002).
The published source zip was identical to the working copy, so there is one commit.
Third-party: an unattributed CIPAddressCtrlEx class and a Pete's AVI Collection
animation (`res/dr_serverhourglass.avi`).
