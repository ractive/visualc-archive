LaPlaya Version 1.2 (26.06.2001)

What's that?
======================================================================================

Most movieplayers are not very easy to use if you want to view a couple of movies in
a row. Playlist are often too complicated to handle. Why not playing just all movies
in a row?

This is exactly what LaPlaya does. It lists all movies in a directory an can play one
clip after the other... Just sit back and watch!

What's new?
======================================================================================
Changes to 1.0:
- The tree view is updated if you select a dir from the file menu
- Key-bindings. See the aboutbox for more info
- Some bugs fixed
- Naughty bug fixed that caused all icons to disappear on Win9x/ME :-)

Known Problems:
======================================================================================
If the settings are changed while a movie is open, this movie can't be played any
more. Open another movie and switch back to the old one to solve this problem.

If you find more jurks or if you have ideas how to improve this program, don't
hesitate to contact me: james@ractive.ch

INSTALLATION
======================================================================================
Window MediaPlayer must be installed on your system!
Run the installation program LaPlaya.exe or LaPlaya_linked.exe :-)

PROBLEMS
======================================================================================
If you get error messages like "...MFCxx.DLL not found..." you don't have installed
the MFC libraries.
You can download a linked version of LaPlaya at:
http://www.ractive.ch/gpl/download/LaPlaya_linked.exe
