# RCServer

ATL plug-in for Windows Media Player 9, generated with Microsoft's WMP plug-in wizard,
that opens a TCP listener on port 4444 (`RCServerSocket`, `AtlSocket`) and maps
incoming text commands to play, pause, next, previous and volume actions on the player.
Counterpart of WinAmpRCServer for Media Player (2003). No licence stated. `wmp.h`,
`wmpplug.h` and `CPropertyDialog.h` are Microsoft SDK files.
