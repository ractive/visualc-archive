# TrackerSkin 1.0

Experimental editor and viewer for the skin INI files of the Sony Ericsson P800
"Tracker" application. Own classes: `CIniFile`, `CPropertyList`, `CSkinButton`,
`CSkinBitmap` and transparent variants, `CValue`. The dialog loads a skin from a
hard-coded path in the author's profile. October 2003, no licence stated.
