Hexer 2.0

What's that?
======================================================================================

Hexer is a small tool to convert numbers to different bases:
- Unsigned integer
- Singed integer
- Octal
- Hexadecimal
- Binary
- double (only supported with 64 Bit)

To convert a number to the other bases, enter it and press ENTER or hit "Calculate".
You can adjust the value of the entered number by hitting the spin buttons in the
bottom right corner.

Hex values can be entered with or without a leading 0x. The values is case insensitive
(0xfa is the same as 0xFA).

Left beside the HEX representation is a button that represents the color of the HEX
Value in the format 0xRRGGBB (as used in HTML). Only the last 6 byte of a number are
used to represent the color.
Press the button to choose a color and get the correspongind HEX Value.

The field in front of the "double" value indicates with precision should be used to
display the double value (this is the amount of digits after the decimal point).

You can choose the bit length with the combo box at the button.

You also can drag values into Hexer. To simplify that, press the pin-button so that
the window will stay on top.
