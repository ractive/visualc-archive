What's that:
================
Use this program to compose your EMELODY ringtone! The produced rintones are EMS
standard, but (as far as I know) only supported by Ericsson phones at the moment!

Compose your ringtone and save it!
 Open Windows-Explorer, right-click on the file and choose
"Send to - Infrared receiver". The ringtone should be transferred to your phone!

About the program:
=================
Valid tones are:
c d e f g a b
(b)d (b)e (b)g (b)a (b)b
#d #e #g #a #b

Uppercase letters mean a long tone (i.e. #C). A "+" in front of a tone means one
octave higher (i.e. "+(b)E")

Use "p" for a pause.

For a detailed description see (all on one line):
http://www.ericsson.com/mobilityworld/developerszonedown/downloads/docs/t68/
t68_at_commands_dg_ver1_external.pdf


If you hit "Play", the tone starts playing at the current cursor position!!!!
Select a part to only play this part!

If you check "Play when changing cursor" you hear any subsequent tone if you use 
the right-arrow to move the cursor within the melody.
